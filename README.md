# 🧬 群友人格克隆插件 v2.0

让 AI 学会群友的说话方式！支持群聊 & 私聊双模式。

## 📋 指令大全

### 克隆人格

| 场景 | 指令 | 说明 |
|------|------|------|
| 群聊 | `克隆 @群友` | 克隆被 @ 的群友人格 |
| 群聊 | `克隆 @群友 -f` | 强制重新分析（覆盖缓存） |
| 私聊 | `克隆 <群号> <QQ号>` | 私聊窗口克隆指定群友 |
| 私聊 | `克隆 <群号> <QQ号> -f` | 强制重新分析 |

### 人格管理

| 指令 | 说明 | 权限 |
|------|------|------|
| `人格切换 <ID>` | 切换到指定人格 | 所有人 |
| `人格切换 default` | 恢复默认人格 | 所有人 |
| `人格列表` | 查看已克隆的人格 | 所有人 |
| `人格详情 <ID>` | 查看人格详细信息 | 所有人 |
| `人格删除 <ID>` | 删除指定人格 | 管理员 |

### 系统设置

| 指令 | 说明 | 权限 |
|------|------|------|
| `管理员注入开关` | 查看当前状态 | 管理员 |
| `管理员注入开关 on` | 开启→仅管理员可注入 | 管理员 |
| `管理员注入开关 off` | 关闭→所有人都可注入 | 管理员 |

## 🔐 管理员注入开关说明

| 状态 | 效果 |
|------|------|
| **ON** (默认) | 只有管理员使用 `克隆` 才会把人格注入 AstrBot 设定 |
| **OFF** | 任何群友使用 `克隆` 都会自动把人格注入 AstrBot 设定 |

> 无论开关状态如何，人格数据都会保存到 `personalities.json`，大家都可以用 `人格切换` 来切换。

## 🔄 重复 ID 策略

**直接覆盖，不弹提示。** 同一群同一人的 ID 固定为 `群号_QQ号`，每次克隆都会覆盖更新。

## 🏗️ 安装

1. 将 `astrbot_plugin_clone_personality` 复制到 `/AstrBot/data/plugins/`
2. 在 WebUI 配置中添加你的用户 ID 到管理员列表
3. 重启或热重载

## 🗂️ 生成的文件

| 文件 | 说明 |
|------|------|
| `personalities.json` | 所有人格数据 |
| `config.json` | 插件配置（管理员注入开关） |
| `active_persona.txt` | 当前激活的人格 ID |
| `current_persona.txt` | 当前注入的人格设定文本 |
